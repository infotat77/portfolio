2026.05.25 Python 自動化 YouTube API

焚き火ASMR動画をYouTubeに自動投稿するシステムを作った話

焚き火の動画クリップとASMR音声・BGMを自動で合成し、メタデータ・サムネイルを生成してYouTubeに投稿するまでを Pythonで完全自動化しました。毎晩23時にMacのlaunchdから自動実行される仕組みも込みで。

なぜ作ったのか

焚き火・ASMR系のYouTubeチャンネルは、一度仕組みを作ってしまえば手間なく運営できる構造に向いています。 「動画生成→メタデータ作成→投稿」の全工程を自動化すれば、人が介入しなくてもチャンネルが動き続けます。 自動化の恩恵を最も受けやすいジャンルとして取り組みました。

パイプライン全体像

1回の実行で以下がすべて自動で行われます。

動画クリップ → 1080p正規化 → ループ延長 → ASMR+BGMミックス → サムネイル生成 → YouTube投稿

技術スタック

役割技術
動画処理・音声ミックスFFmpeg 8.1.1（subprocess経由）
サムネイル加工Pillow（フレーム抽出・グラデーション・テキスト描画）
メタデータ生成Pythonテンプレート（タイトル5種×用途×ジャンルの組み合わせ）
YouTube投稿YouTube Data API v3（OAuth2・resumable upload）
定期実行macOS launchd（毎晩23:00）
エラー通知Discord Webhook

実装で工夫した点

動画尺のランダム化

毎回同じ尺の動画を投稿するとYouTubeの自動投稿検知に引っかかるリスクがあります。 --hours 1 を指定した場合でも実際の尺は60〜70分のランダムになるよう実装しました。 

base_seconds = int(args.hours * 3600)
target_seconds = base_seconds + random.randint(0, 600)  # +0〜10分

ASMR + BGMの2トラックミックス

焚き火のパチパチ音（ASMR）を主役にしつつ、Lo-fiなどのBGMを背後に流すミックスをFFmpegの amix フィルターで実装。音量バランスは .env で調整可能にしました。 

[0:a]volume=1.0[asmr];[1:a]volume=0.35[bgm];
[asmr][bgm]amix=inputs=2:duration=longest

サムネイルの自動フォントサイズ調整

タイトルの長さによってテキストが不自然に改行されないよう、44pxから28pxまで2pxずつ試して 2行以内に収まる最大フォントサイズを自動選択する仕組みを実装しました。

BGMのランダム選曲

assets/bgm/ フォルダに複数の楽曲を入れておくと、毎回ランダムで1曲を選択します。 現在15曲をローテーションしており、動画ごとに雰囲気が変わります。

ディレクトリ構成

campfire_auto_post/
├── main.py              # オーケストレーター（CLI）
├── src/
│   ├── video_generator.py   # 動画正規化・ループ
│   ├── audio_processor.py   # ASMR+BGMミックス
│   ├── video_composer.py    # フルパイプライン
│   ├── metadata_generator.py # タイトル・概要欄・タグ生成
│   ├── thumbnail_creator.py  # サムネイル加工
│   └── youtube_uploader.py  # YouTube API投稿
├── assets/
│   ├── video/   # 焚き火動画クリップ
│   ├── audio/   # ASMR音声
│   └── bgm/     # BGM（15曲）
└── cron_setup.sh  # launchd登録スクリプト

やってみてわかったこと

  • YouTube APIのOAuth2認証はチャンネル作成・電話番号認証が事前に必要で、セットアップが一番手間だった
  • カスタムサムネイルのアップロードもチャンネル認証が必要（新チャンネルあるある）
  • FFmpegは非常に強力で、動画ループ・音声ミックス・フレーム抽出がコマンド1本で完結する
  • Pillowの絵文字描画は非対応なため、タイトルテキストから絵文字を除去する処理が必要だった
