2026.06.06 Python CLI 自動化

テンプレート×ランダム生成でX投稿文案を自動生成するCLIツールを作った話

投資系Xアカウントの投稿ネタが続かない問題を、Claude API不使用・完全ローカルのテンプレートエンジンで解決。 インタラクティブな採用レビュー・週間スケジュール一括生成・重複回避履歴管理まで備えた CLI ツールです。

なぜ作ったのか

投資系の X アカウントへ定期投稿しようとすると、毎回「何を書けばいいか」で手が止まる。 Claude API を使って生成するという選択肢もあったが、API コストが積み重なること、 そして投稿文は人間がレビューして初めて価値が出ると思い、 「AIに文章を作らせる」のではなく「テンプレートとランダム組み合わせで文案を提示する」ツールにすることにした。

設計方針

  • API 不使用・完全ローカル — 外部サービスへの依存ゼロ。コスト永久ゼロ
  • テンプレート＋プレースホルダー — 投稿の「型」は人間が書き、値だけランダムに差し替える
  • 140 字チェック — 生成後に自動計測。超えても警告するだけで止めない（確認できることが大事）
  • 人間がレビューして手動投稿 — 自動投稿はしない。文案を見て選ぶ体験を設計する

ファイル構成

templates/*.txt → generator.py → main.py (CLI) → stdout / output/
ファイル役割
templates/nisa.txt 他3本--- 区切りのテンプレート群（各8〜9件）
config.pyPLACEHOLDERS（候補値リスト）・HASHTAGS・WEEKLY_SCHEDULE
generator.pyテンプレート読込・re.sub によるプレースホルダー置換・履歴管理
main.pyargparse CLI・インタラクティブモード・週間生成ロジック
output/history.json採用済みテンプレートのハッシュと使用日時を記録

テンプレートの仕組み

templates/nisa.txt のように、テーマごとのファイルに投稿の「型」を --- で区切って複数書く。 プレースホルダーは {period} や {tag1} のように記述し、 config.py の候補値リストからランダムに差し替える。 

NISAを始めて{period}が経ちました。意識して変わったのは{change}です。📈 #{tag1} #{tag2}
---
{monthly}をNISAに積み立てるだけで、{years}年後には大きく変わります。💪 #{tag1} #{tag2}
---
暴落が来たらNISAは「セール中」と思うようにしています🛒 #{tag1} #{tag2}
# config.py（抜粋）
PLACEHOLDERS = {
    "period": ["3ヶ月", "半年", "1年", "2年", "3年"],
    "change": ["節約習慣", "長期思考", "複利の力への気づき"],
    ...
}
HASHTAGS = {
    "nisa": ["NISA", "新NISA", "積立投資", "資産形成", ...],
}

3つの主要機能

① 通常生成モード

テーマと件数を指定するだけ。重複回避のため、直近 14 日間に採用したテンプレートは 優先的に除外される（使い切ったらリセット）。 

python3 main.py --theme nisa --count 5 --save

② インタラクティブモード（--interactive）

1 件ずつ表示し、キー操作でレビューできる。採用（a）・再生成（r）・ スキップ（s）・終了（q）。 採用した瞬間に履歴へ記録され、次の生成に反映される。 

====================================
【投稿案 2/5】
---
毎月5万円をNISAに積み立てるだけで、30年後には大きく変わります。💪
#新NISA #長期投資
---
文字数：55字
====================================
[a] 採用  [r] 再生成  [s] スキップ  [q] 終了  >

③ 週間スケジュール生成（--week）

月〜日の 7 日分をテーマローテーションで一気に生成し、output/week_YYYYMMDD.txt に保存。 1 週分のポストストックが一発で完成する。 

python3 main.py --week

重複回避の設計

採用した投稿は、使ったテンプレートの MD5 ハッシュ（先頭 8 桁）を output/history.json に記録する。次回生成時に直近 14 日以内のハッシュと 照合し、フレッシュなテンプレートを優先選択する。全テンプレートが使い終わったら プールをリセット（同じ文が繰り返されない工夫）。 

# output/history.json（抜粋）
{
  "nisa": [
    { "hash": "950836d8", "used_at": "2026-06-06T13:34:14", "preview": "NISAは「投資のハードル」" }
  ]
}

やってみてわかったこと

  • テンプレートの「型」と候補値の組み合わせだけで、思った以上にバリエーションが生まれる
  • インタラクティブモードを作ったことで「使う」楽しさが生まれた。採用 / 再生成 を繰り返す体験がちょうどよい
  • 重複回避のハッシュ管理は単純だが効果大。同じ文が2日連続で出てくるストレスがなくなった
  • getch()（tty/termios）はキーを押すだけで反応するので UX がよい
  • Python 3.9 では dict | None 記法が使えない。from __future__ import annotations を忘れずに
