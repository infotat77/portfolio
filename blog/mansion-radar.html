2026.06.01 Python Notion API Google Sheets 個人開発

マンション購入リサーチをフル自動化した——SUUMO × Notion × Google Sheets × Streamlit

「SUUMOを1件ずつスクロールするのが辛い」という課題から始まり、 HTMLパース→JSON→Notion・Google Sheets自動同期→Streamlitダッシュボードという 3媒体同時出力のシステムに育てました。中古・新築の分類、間取り・予算フィルター、 「気になる」ボタンによる夫婦共有まで実装しています。

なぜ作ったのか

妻と都内マンションの購入を検討しており、候補エリアの相場を把握したいと思っていました。 ただ、SUUMOを1件ずつスクロールして比べるのは非常に非効率で、「坪単価」のような比較軸も手計算になります。 「一覧で俯瞰したい」「夫婦で同じ画面を見ながら話し合いたい」という課題を解決するために作りました。

システム構成

週1回だけSUUMOのHTMLを手動保存する以外は、データ加工・Notion登録・ダッシュボード表示がすべて自動で行われます。

SUUMO HTML保存 → BeautifulSoupパース → ローカルJSON → Notion DB ＋ Google Sheets → Streamlit
役割技術
HTMLパースBeautifulSoup4（中古・新築の両フォーマット対応。価格範囲は最小値を取得）
Notion同期notion-client（完全同期：消えた物件を自動アーカイブ）
Sheets同期gspread（条件付き書式・ステータス色分け・ヘッダー固定）
ダッシュボードStreamlit + Plotly + Folium（散布図・地図・Notion管理タブ）
ジオコーディングgeopy Nominatim + ローカルキャッシュ（住所→座標変換）

実装で工夫した点

坪単価の自動計算

マンション比較で最も重要な「坪単価」は、Notion側のFormulaプロパティで自動計算するようにしました。 Pythonからは価格と面積だけを送れば、Notionが price / area * 3.3 を自動で計算します。

重複チェックによる差分登録

同じHTMLを再実行しても物件が重複登録されないよう、Notion APIでURL一致検索をして 既存データはスキップする仕組みを実装しました。週次で実行しても安心です。 

def _already_exists(notion, database_id, url):
    res = notion.databases.query(
        database_id=database_id,
        filter={"property": "URL", "url": {"equals": url}},
    )
    return len(res.get("results", [])) > 0

Notionのビュー設計

Notion DB にはテーブルビューとステータス別ボードビューの2つを用意しました。 テーブルビューで坪単価順にソート、ボードビューで「気になる」「見学予定」「候補外」の ステータス管理ができ、夫婦間の情報共有ツールとして機能しています。

Streamlitダッシュボード

横軸を面積・縦軸を坪単価にした散布図で、色をエリア（区）別に分けることで 「同じ面積でも目黒区と世田谷区でどれだけ坪単価が違うか」が一目でわかります。 ホバーで物件名・価格・最寄り駅も表示されます。

アップデートで追加した機能（2026.06）

  • Google Sheets同期 — gspreadでシートを完全同期。ステータス列の条件付き書式・ヘッダー固定も自動適用
  • 中古/新築の分類 — パーサーが自動判定し、Notion・Sheets・Streamlitすべてに反映
  • フィルター強化 — 予算上限・最低間取り・エリア（区）・物件種別。設定値はファイルに永続化
  • 「気になる」ボタン — 散布図で物件をクリック→ボタン1つでNotionステータスを変更。夫婦の検討リストとして機能
  • Streamlit UI刷新 — ヒーローバナー・物件詳細カード・Google Fonts統一。ライトテーマ固定

やってみてわかったこと

  • SUUMOは価格・間取りを範囲表示（6000万〜1億円）するため、最小値だけ取るよう正規表現を調整する必要があった
  • Notion APIは直感的だが、「完全同期」（消えた物件のアーカイブ）を実装するとfetch→diff→updateの3ステップになる
  • Google Sheets APIは条件付き書式がbatchUpdateのJSONで書く必要があり、ドキュメント読み込みに時間がかかった
  • Streamlitのダークモード対応は`config.toml`でライトテーマ固定が最も確実
  • フィルターのデフォルト値をJSONに保存してセッション状態と橋渡しする実装が意外と考慮点が多かった
