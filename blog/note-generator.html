2026.05.27 Python Gemini API 自動化

Gemini API で Note 投資記事を自動生成するシステムを作った話

Yahoo!ニュースのRSSからその日のトレンドキーワードを取得し、Gemini APIで Note（note.com）向けの 投資・資産運用記事を自動生成するシステムを作りました。毎朝9時にcronで実行され、 キーワード選定から記事生成・保存まで手作業ゼロで完結します。

なぜ作ったのか

Note で投資・資産運用の記事を継続的に書こうとしていましたが、「今日何について書くか」を考えるだけで 30分、執筆に1〜2時間かかっていました。週に数本書き続けるのはすぐ挫折すると判断し、 記事生成を自動化することにしました。

「書くこと」ではなく「選んで投稿すること」だけを人間の仕事にするのが目標です。

パイプライン全体像

毎朝9時のcron実行で以下がすべて自動で行われます。

Yahoo! RSS取得 → Geminiがキーワード選定 → プロンプト組み立て → Geminiで記事生成 → 品質チェック → output/*.md 保存

技術スタック

役割技術
記事生成Gemini API（google-genai SDK）/ models/gemini-2.5-flash
トレンド取得Yahoo!ニュース RSS + Python標準 xml.etree
定期実行macOS cron（毎朝9:00）
設定管理PyYAML + python-dotenv
品質チェック正規表現による文字数・免責事項・ハッシュタグ検証

実装で工夫した点

Gemini に2回仕事をさせる構成

RSSから取得した見出しをそのままキーワードにするのではなく、まず1回目のAPI呼び出しで 「今日の見出しの中から投資記事テーマとして最適なキーワードを1つ選んでほしい」とGeminiに判断させます。 2回目で実際の記事を生成します。これにより、ニュースの文脈に即したキーワードが得られます。 

prompt = f"""以下は今日の経済・マーケットニュースの見出しです。
Note の投資記事テーマとして最適なキーワードを1つ選んでください。

【直近の記事テーマ（重複を避ける）】
{used_text}

キーワードのみを1行で出力してください。"""

重複記事の検知

output/ フォルダ内の既存記事を読み込み、キーワードが一定数以上一致するファイルがあれば 警告を出す仕組みを実装しました。同じテーマの記事が溜まりすぎることを防ぎます。

品質チェックの自動化

生成された記事に対して3つのチェックを自動実行します。

  • 文字数チェック: 目安文字数の80%以上あるか
  • 免責事項チェック: 「免責事項」または「情報提供を目的」の文言があるか
  • ハッシュタグチェック: 指定数のハッシュタグが含まれているか

プロンプトテンプレートの外部化

記事のトーン・構成・禁止表現などのルールを prompts/investment.md に切り出しました。 コードを変えずにプロンプトを調整できるため、記事品質の改善サイクルが高速になりました。

ファイル構成

note-generator/
├── generate.py    # キーワード指定で1記事生成
├── auto.py        # RSSトレンドで自動生成
├── thumbnail.py   # Pillowサムネイル生成
├── save.py        # クリップボードから記事を保存
├── run_auto.sh    # cron用ラッパー
├── config.yaml    # モデル・デフォルト値の設定
├── .env           # GEMINI_API_KEY
├── prompts/
│   └── investment.md   # 記事生成プロンプトテンプレート
├── output/        # 生成された記事（日付_キーワード.{md,png,txt}）
└── logs/          # cron実行ログ

2026.06.03 アップデート

記事生成後のワークフローをさらに自動化しました。

デスクトップランチャー（.command）

ターミナルを開かずにダブルクリックで起動できる .command ファイルをデスクトップに配置しました。 メニューから「キーワード指定」か「今日のニュースから自動生成」を選択でき、 キーワードをそのまま入力すると記事生成に直行します。

Pillowによるサムネイル自動生成

記事生成と同時に、note.com のサムネイル用 PNG（1280×670px）を自動生成するようにしました。 ヒラギノ角ゴシックを使用した紺グラデーション背景＋ゴールドアクセントのデザインで、 タイトルを読点・スペースなどの自然な区切り位置で折り返し、フォントサイズはタイトル長に応じて自動調整します。

外部APIを使わずPillowのみで完結するため、追加コストなしで毎回生成されます。

Gemini 画像プロンプトの自動生成

記事内容をもとに、無料版 Gemini（gemini.google.com）に貼り付けるだけで 記事テーマに合った画像を生成できる英語プロンプトを自動生成し、.txt ファイルに保存します。

記事生成（.md） → サムネイル生成（.png） → 画像プロンプト生成（.txt） → 3ファイルを自動で開く

ハマったこと

  • Gemini APIのクォータ問題: 新規プロジェクトで limit: 0 エラーが発生。 GCPの請求情報を設定するまで無料枠のクォータが付与されない仕様だった。 APIキーの再発行では解消せず、請求アカウントの紐付けが必要だった。
  • モデル名の廃止: gemini-2.0-flash-lite が新規ユーザーに対して 提供終了になっており404エラー。gemini-2.5-flash に切り替えで解消。
  • google-generativeai の廃止: 旧パッケージ google-generativeai は 非推奨になっており、google-genai への移行が必要だった。 インポートが import google.generativeai から from google import genai に変わる。

今後やりたいこと

  • 生成した記事の中からタイトルを自動選択してNotionに下書き保存
  • 過去記事のパフォーマンス（スキ数）をフィードバックしてキーワード選定を改善
  • 複数ジャンル（不動産・暗号資産・節税）への展開
